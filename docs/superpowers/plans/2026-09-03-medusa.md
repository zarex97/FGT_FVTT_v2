# Medusa Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Medusa from `char_orig_sheets/Copia de Medusa.md` completely — every clause of all ten abilities working, with the fourteen general engine features they need built rather than deferred.

**Architecture:** Four layers, enforced by `tools/check-layers.mjs`: `domain/` (pure, no Foundry globals) → `rules/` (pure) → `engine/` (writes through intents) → `apps/`. Content is YAML in `packs/_source/**` compiled by `npm run build:packs`. Every new mechanic is general — a Medusa-shaped special case is a plan failure.

**Tech Stack:** Foundry VTT v14, ES modules, Vitest, YAML content pipeline.

**Spec:** [`docs/superpowers/specs/2026-09-03-medusa-design.md`](../specs/2026-09-03-medusa-design.md)

## Global Constraints

- **Layer discipline.** `module/domain` and `module/rules` may not reference `game`, `canvas`, `CONST`, `Hooks`, `foundry`, `ui`, `CONFIG`, `PIXI`, `window` or `document` — ESLint `no-restricted-globals` enforces it. `module/data` may import from `domain` **only**.
- **Every engine `token.update()` touching `x, y, elevation, width, height, depth, shape, level` must pass `{fgtForced: true}`**, or Foundry's `onPreMove` silently refuses it.
- **The world must be shut down before `npm run build:packs`**, or LevelDB throws `EBUSY`. Allow ~25s after `game.shutDown()` for the lock to release.
- **Checks that must pass before every commit:** `npm run lint` (eslint + check-layers), `npx vitest run`, `npm run validate:content`, `npm run check:templates`, `npm run check:manifest`.
- **Docs are part of every commit.** The affected chapter in `00`–`44` must change, not only Ch. 45. Update `CHANGELOG.md` under `[Unreleased]`.
- **Live-test in the `fgt2026` world as the GM user** (no password) before each commit is final. Report measurements, not assertions.
- **Commit message footer, exactly:**
  ```
  Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_014hZGmjdxHK6gCyudTcXi3S
  ```
- **Content vocabulary is closed.** `severity` is `normal|instakill|death|erase`; `volatility` carries `mental`; `chooser` is `all|nearest|random|chosen`; damage `modifierKey` must be one of `MODIFIER_KEYS` (`module/rules/damage/pipeline.mjs`). Inventing a key compiles and is silently unread — `npm run validate:content` catches the ones it knows; assume it does not know yours.
- **A new top-level key on a unit YAML must be added to `actorSystem()` in `tools/lib/content.mjs`**, or it compiles to its schema default. `unitKeyCoverage` in `validate-content` now fails the build on this.

```js
/**
 * @file Effect families — an umbrella name for a set of effects.
 * @see docs/A-effect-catalogue.md, docs/11-effect-engine.md
 *
 * Layer 2 (rules). Pure.
 *
 * `Bind` is not an effect anybody applies; §A defines it as an umbrella over
 * ten that are. Declared ON each member rather than as a central list, so a
 * new binding effect counts by saying so about itself.
 */

/**
 * The families an effect declares.
 * @param {object|null} def
 * @returns {string[]}
 */
export function familiesOf(def) {
  return Array.isArray(def?.families) ? def.families : [];
}

/**
 * Does this unit carry any effect of the named family?
 *
 * A **suppressed** instance does not count. Metamorphosis pays out against
 * *"Units inflicted with Bind effects"*, and a suppressed Stun is not binding
 * anybody -- the same reading `rules/control.mjs#findCharm` takes.
 *
 * @param {object} unit a unit snapshot
 * @param {string} family
 * @param {Map<string, object>} registry defId → definition
 * @returns {boolean}
 */
export function unitHasFamily(unit, family, registry) {
  const suppressed = new Set(
    (unit?.effectInstances ?? []).filter((i) => i.suppressed).map((i) => i.defId),
  );
  return (unit?.effects ?? []).some((id) =>
    !suppressed.has(id) && familiesOf(registry?.get?.(id)).includes(family));
}
```

- [ ] **Step 3: Add `panelsBetween` to `domain/geometry.mjs`**

```js
/**
 * The panels strictly between two panels, exclusive of both ends.
 *
 * Only meaningful on a shared row, column or exact diagonal — which is what
 * "between" means on a grid with no line of sight. Anything off those three
 * axes returns `[]`: it has no panels between it and the origin, so nothing can
 * obstruct it. That is the conservative reading and the only one Medusa's
 * single worked example supports (Ch. 44 §44.3).
 *
 * `line` projects a DIRECTION for a length; this walks to a given panel, which
 * nothing did before.
 *
 * @param {GridOffset} a
 * @param {GridOffset} b
 * @returns {GridOffset[]} in order from `a` toward `b`
 */
export function panelsBetween(a, b) {
  const di = b.i - a.i;
  const dj = b.j - a.j;
  const straight = di === 0 || dj === 0 || Math.abs(di) === Math.abs(dj);
  if (!straight) return [];

  const steps = Math.max(Math.abs(di), Math.abs(dj));
  const step = { i: Math.sign(di), j: Math.sign(dj) };
  const out = [];
  for (let n = 1; n < steps; n++) out.push({ i: a.i + step.i * n, j: a.j + step.j * n });
  return out;
}
```

- [ ] **Step 4: Implement `module/rules/targeting/facing.mjs`**

```js
/**
 * @file Two per-ability targeting prerequisites: where the caster is looking,
 * and what is in the way.
 * @see docs/44-case-expanded-roster.md §44.3 (D44.8), docs/09-targeting.md
 *
 * Layer 2 (rules). Pure.
 *
 * There is **no general line of sight in F/GT** and D44.8 decided there will
 * not be. Medusa's Mystic Eyes is the only ability in the corpus that asks, so
 * both of these are opt-in flags on one ability rather than a board-wide rule.
 */

import { coneOf, panelsBetween } from "../../domain/geometry.mjs";

/**
 * Is the target in the caster's front quadrant?
 *
 * > *"can only be used if Medusa is facing the targeted Unit."*
 *
 * `coneOf` has answered this since it was written and nothing had ever called
 * it — Ch. 14 §14.5's directional Evade modifiers, its intended consumer, are
 * still unbuilt.
 *
 * @param {object} caster
 * @param {object} target
 * @returns {boolean}
 */
export function facingAllows(caster, target) {
  if (!caster?.panel || !target?.panel) return false;
  if (caster.id === target.id) return true;
  return coneOf(caster.facing ?? "n", caster.panel, target.panel) === "front";
}

/**
 * Is there nothing standing between caster and target?
 *
 * > *"Cannot be used on a Unit if there is an obstacle/obstruction between
 * > Medusa and the target Unit. (Example: Unit [Cannot be targeted] — Unit
 * > [Can be targeted] — Medusa)"*
 *
 * A Civilian does not obstruct — they are bystanders, not cover — and neither
 * does a defeated unit, whose token stays on the board.
 *
 * @param {object} caster
 * @param {object} target
 * @param {object} board
 * @returns {boolean}
 */
export function pathClear(caster, target, board) {
  if (!caster?.panel || !target?.panel) return false;
  const between = panelsBetween(caster.panel, target.panel);
```

```js
/**
 * @file Branch selection for a check phase.
 * @see docs/14-checks-and-randomness.md, docs/15-abilities.md §15.2
 *
 * Layer 2 (rules). Pure.
 *
 * A check phase used to be one Luck check with `onSuccess`/`onFail`. Medusa's
 * Mystic Eyes is three outcomes chosen by what the target IS, one of which
 * rolls again on failure -- so the phase needs branches, and a branch needs to
 * be able to hold another check.
 */

import { testPredicate } from "../predicate.mjs";

/**
 * The branch this phase takes against this target.
 *
 * A phase with no `branches` IS its own branch: that is the shape every
 * shipped `check` phase uses and it must keep working.
 *
 * @param {object} phase
 * @param {Set<string>} options the TARGET's option set
 * @returns {object|null}
 */
export function selectBranch(phase, options) {
  if (!Array.isArray(phase?.branches)) return phase ?? null;
  for (const branch of phase.branches) {
    const when = branch.when ?? [];
    if (when.length === 0) return branch;          // the catch-all
    if (testPredicate(when, { options })) return branch;
  }
  return null;
}
```

```js
async function runCheckPhase(phase, ability, state, defender, depth = 0) {
  // A nested branch is "roll again", not "roll for ever".
  if (depth > 2) return [];

  const branch = selectBranch(phase, rollOptionsFor({ attacker: defender }));
  if (!branch) return [];

  const kind = phase.check ?? branch.check ?? "luck";
  const roll = await new Roll("1d20").evaluate();
  const plan = checkPlan(defender, kind);

  // A LUCK check costs 1 Luck whether or not it succeeds (Ch. 14) and consults
  // the attacker's Luck; an AGILITY check does neither -- it is the same pair
  // Cover (§16.4 rule 4) resolves with.
  const outcome = kind === "luck"
    ? luckCheck({ /* ...exactly today's arguments... */ })
    : resolveCheck({
      roll: roll.total,
      target: defender[kind],
      table: plan.forceTable === "unfavourable" ? "unfavourable" : "favourable",
      modifiers: plan.modifiers,
    });

  const intents = [I.log({ kind: "check", check: kind, unitId: state.defenderId, /* ... */ })];
  if (kind === "luck") intents.unshift(I.statDelta(state.defenderId, "luck.value", -1));
  await applyBatch(intents, "np:check");

  const taken = outcome.success ? branch.onSuccess : branch.onFail;
  if (!taken) return [];

  // "If Failed, roll again." A branch that is itself a check recurses.
  if (taken.check || taken.branches) {
    return runCheckPhase({ ...taken, kind: "check" }, ability, state, defender, depth + 1);
  }

  const out = [];
  // "reduce the DU's Agility by 2" -- an outcome that is not an effect.
  for (const d of taken.statDeltas ?? []) {
    out.push(I.statDelta(state.defenderId, d.path, d.delta));
  }
  if (out.length > 0) await applyBatch(out, "np:check:stat");
  if (taken.effects?.length) {
    return applyDeclaredEffects(taken.effects, ability, state, defender, {
      ignoresResistanceFrom: phase.ignoresResistanceFrom ?? [],
    });
  }
  return [];
}
```

```js
/**
 * @file Blood Fort Andromeda's four Bloodmarks, and the square they define.
 * @see docs/43-bounded-fields.md §43.4 (`markDefined`), §43.10
 *
 * Layer 2 (rules). Pure.
 *
 * The only field in the game that is BUILT rather than cast: four Actions over
 * four turns, and the area exists when the fourth completes a legal square.
 */

/** "the four corner panels of a 5x5, 7x7, or 9x9 panel area". */
export const LEGAL_SIZES = Object.freeze([5, 7, 9]);

/**
 * The area four marks define, or `null` if they define none.
 *
 * Corners, not merely four panels: the sheet says *"the four CORNER panels"*,
 * so three in a row and a fourth adrift is not a field. A square, not a
 * rectangle, and only at the three stated sizes.
 *
 * @param {Array<{i: number, j: number}>} marks
 * @returns {{panels: Array<{i: number, j: number}>, size: number}|null}
 */
export function squareFrom(marks) {
  if (!Array.isArray(marks) || marks.length !== 4) return null;

  const is = [...new Set(marks.map((m) => m.i))].sort((a, b) => a - b);
  const js = [...new Set(marks.map((m) => m.j))].sort((a, b) => a - b);
  // Exactly two distinct rows and two distinct columns is what "four corners"
  // means; anything else is four panels that happen to be four panels.
  if (is.length !== 2 || js.length !== 2) return null;

  const height = is[1] - is[0] + 1;
  const width = js[1] - js[0] + 1;
  if (height !== width || !LEGAL_SIZES.includes(height)) return null;

  // All four combinations must actually be present -- two rows and two columns
  // could otherwise be satisfied by a duplicate.
  const seen = new Set(marks.map((m) => `${m.i},${m.j}`));
  for (const i of is) for (const j of js) if (!seen.has(`${i},${j}`)) return null;

  const panels = [];
  for (let i = is[0]; i <= is[1]; i++) for (let j = js[0]; j <= js[1]; j++) panels.push({ i, j });
  return { panels, size: height };
}
```
