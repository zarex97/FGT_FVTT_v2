# Mannanán mac Lir — Implementation Plan

**Goal:** Build Mannanán from `char_orig_sheets/Copia de Mannanán mac Lir.md` completely — every
clause of all thirteen abilities working, with the twelve general engine features they need built
rather than deferred.

**Spec:** [`docs/superpowers/specs/2026-09-07-mannanan-design.md`](../specs/2026-09-07-mannanan-design.md)

## Global Constraints

- Layer discipline (`tools/check-layers.mjs`): `domain/` → `rules/` → `engine/` → `apps/`.
- The world must be shut down before `npm run build:packs` (`node tools/fgt-rebuild.mjs fgt2026`).
- Checks before every commit: `npm run lint`, `npx vitest run`, `npm run validate:content`,
  `npm run check:templates`, `npm run check:manifest`.
- Docs are part of every commit: the affected chapter in `00`–`44` **and** Ch. 45.
- Live-test in `fgt2026` as the GM (no password). Report measurements, not assertions.
- New rule-element keys go in **both** `EXECUTORS` (`module/rules/elements.mjs`) and
  `RULE_ELEMENT_KEYS` (`tools/lib/content.mjs`); `test/unit/elements.test.mjs` holds them together.
- A new top-level key on a unit YAML must be added to `actorSystem()` in `tools/lib/content.mjs`.
