# Raikou Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Minamoto no Yorimitsu plays exactly as `char_orig_sheets/Copia de Raikou.md` reads — nine clauses, including a mode held on by her Master's position, a modifier whose subject is another modifier's magnitude, four clones with per-clone armament that inherit her passives, and a Noble Phantasm that resolves as five attacks under two different rule sets.

**Architecture:** Every task pairs an engine addition with the clause that consumes it. Nothing lands inert — this project names "a rule that is right and inert" as its dominant defect. Raikou is unusual in that her hardest class skill is *already built*: `domain/tables.mjs` cites her Mad Enhancement `EX` row by name, so every number on her sheet reproduces from the tables untouched and the work is entirely in the six clauses that need mechanisms nothing has.

**Tech Stack:** Foundry VTT v14, vanilla ESM, vitest, YAML content compiled by `tools/build-packs.mjs`.

**Spec:** [`docs/superpowers/specs/2026-09-12-raikou-design.md`](../specs/2026-09-12-raikou-design.md)

## Global Constraints

- **Layer rule.** `domain` (1) ← `rules` (2) ← `engine` (3) ← `apps`/`documents` (4). `rules/` and `domain/` never touch `game`, `canvas`, `ui`, `Hooks`. `npm run lint` runs `tools/check-layers.mjs`.
- **Closed vocabularies, enforced at build time.** Check the value exists before authoring:
  - anchors — `self`, `targetUnit`, `withinRange`, `selfEdgeAdjacent`, `fieldEdge`, `zone`, `movementPath`, `platform`, `global`, `sourceOfAttack`
  - shapes — `point`, `unit`, `square{size}`, `rect{w,h}`, `chebyshevRadius{r}`, `attackRange{r}`, `ring{r}`, `line{…}`, `orientedRect{short,long}`, `path`, `zone{zoneId}`, `banded{bands}`
  - `selection.chooser` — `all`, `nearest`, `random`, `chosen`
  - `modifierKey` — the closed set at `rules/damage/pipeline.mjs` `MODIFIER_KEYS`
  - roll options — every option a predicate names must match a pattern generated from `rules/facets.mjs#FACETS`, held by `test/unit/options.test.mjs`
  - rule element keys — one entry per key in `rules/elements.mjs#EXECUTORS`, mirrored in `rules/authoring/elements.mjs`, held in **both** directions by `test/unit/authoring-elements.test.mjs`
  - phase kinds — `PHASE_IDS` (`rules/authoring/phases.mjs`)
  - requirement kinds — `REQUIREMENT_IDS` (`rules/authoring/requirements.mjs`)
- **`actorSystem()` / `itemSystem()` in `tools/lib/content.mjs` are allowlists.** An authored field absent from them compiles to its schema default and the clause silently does nothing. `npm run validate:content` refuses unknown fields.
- **Every new localization key must resolve in `lang/en.json`** to exactly the English in the descriptor — `test/unit/authoring-i18n.test.mjs` holds both together.

## Rulings (spec §2 — do not re-litigate)

- **R1** — *"N times"* on an effect application is a **use count**, not a stack count. With a duration stated, both apply and the buff ends on whichever comes first. Damage repetition (*"deal damage four times"*) is unaffected.
- **R2** — Mystery Slayer's Demi-/Pseudo-Servant exclusion covers the **whole skill**, including the Demonic clauses. Sitonai is the one exception, named by `target:contentId:sitonai`.
- **R3** — the `raikou` buff's ⅓◈ comes off **both** Noble Phantasms (`scope: np`).
- **R4** — Tenmōkaikai's clone panels are **facing-relative**; a blocked panel displaces that clone outward along the same axis, and a clone with nowhere to go does not appear and says so.
- **R5** — Tenmōkaikai's +50%/Shock rider applies to **every attack Raikou makes**, not only Normal Attacks.
- **R6** — Dohatsu Tenshou's four sub-attacks **are** Normal Attacks for every rider. Only Mad Enhancement is exempt.
- **R7** — effects land on a Unit that was **hit**, whether or not the damage number reached it.
- **R8** — her Normal Attack uses **BA(STR) = 150**. She is **not** a Magus.
- **R9** — her Class container is **Berserker**.

### Task 1: A hit that dealt zero still applies its riders

**Files:**

- Create: `test/unit/zero-damage-riders.test.mjs`

**Interfaces:**
- Consumes: nothing.
- Produces: the behaviour every later task's on-hit riders depend on. Nothing in Raikou's kit is named here — this is a corpus-wide correction that lands first so her clauses inherit it rather than work around it.

**The ruling (spec R7):**
> *"Every unit that was hit, even if they didn't take damage. That's how it should be for every Attack that also applies effects."*

**The defect.** `engine/attack.mjs`'s `"damage"` case runs the ability-declared riders on `(skipped || veiled) ? [] : await applyAbilityEffects(...)` — i.e. whenever the attack was not suppressed — and then gates the *event-declared* riders one line later on `result.total > 0`. The two halves of "riders" disagree, and the disagreement is invisible because it only shows when a defender's reductions happen to reach zero.

Create `test/unit/zero-damage-riders.test.mjs`:

```js
/**
 * @file A hit that dealt zero is still a hit.
 * @see docs/superpowers/specs/2026-09-12-raikou-design.md §5 (R7)
 *
 * Layer 3 behaviour, tested at the one seam that is pure: the predicate the
 * damage case uses to decide whether the event rungs fire. The full flow needs
 * a world and is live-tested; this holds the decision itself.
 */

import { describe, it, expect } from "vitest";
import { ridersFire } from "../../module/engine/attack.mjs";

describe("whether a resolved Damage Step fires its on-hit riders", () => {
  it("fires them on an ordinary hit", () => {
    expect(ridersFire({ skipped: null, result: { total: 120 } })).toBe(true);
  });

  it("fires them on a hit whose total was reduced to zero", () => {
    // A defender whose Def Up, Dmg Cut or Ward ate the whole number was still
    // HIT. Under the old `result.total > 0` gate every on-hit rider in
    // Appendix A -- Bleed Atk, Queen's Poison, Serenity's daggers, Nemo's
    // Slow, Karna's Burn -- silently did nothing against a well-armoured
    // target, while the ability-declared riders one line above still landed.
    expect(ridersFire({ skipped: null, result: { total: 0 } })).toBe(true);
  });

  it("does NOT fire them when the attack was suppressed outright", () => {
    // "If Heads, no damage AND EFFECTS are received." A complete negation
    // refuses the riders by the same coin that refused the damage.
    expect(ridersFire({ skipped: "Rho Aias", result: { total: 0 } })).toBe(false);
  });

  it("does NOT fire them behind a concealment veil", () => {
    expect(ridersFire({
      skipped: null,
      result: { total: 90, flags: { concealmentVeil: { effects: false } } },
    })).toBe(false);
  });
});
```

- [ ] **Step 3: Extract the decision and widen it**

In `module/engine/attack.mjs`, above the `resolveAttack` export, add:

```js
/**
 * Does a resolved Damage Step fire its event-declared on-hit riders?
 *
 * **Hit, not hurt.** This gate read `!skipped && result.total > 0` from the day
 * it was written, while `applyAbilityEffects` one line below it ran on
 * `!(skipped || veiled)` -- so the two halves of "riders" disagreed about a
 * defender whose reductions reached zero. A Unit that was hit for nothing was
 * still hit: its Bleed Atk, its Queen's Poison, Serenity's daggers and Karna's
 * Burn all pay out, and only an attack that was SUPPRESSED (a complete
 * negation, *"no damage and effects are received"*) or VEILED by concealment
 * refuses them.
 *
 * `damageStepEnd` is deliberately NOT routed through this. Scáthach's Alpi is
 * *"at the end of the Damage Step when a successful Attack is performed"*,
 * which is a clause about the attack succeeding rather than about delivering
 * an effect, and widening it would be extending the ruling rather than
 * applying it.
 *
 * @param {object} args
 * @param {string|null} args.skipped what suppressed the damage, if anything
 * @param {object} args.result the finished damage result
 * @returns {boolean}
 */
export function ridersFire({ skipped, result }) {
  if (skipped) return false;
  return result?.flags?.concealmentVeil?.effects !== false;
}
```

Then, in the `"damage"` case, replace the two rider gates (leave `fireDamageStepEnd` exactly as it is):

```js
      // Riders, which need the victim as well as the fact that it landed.
      const riders = ridersFire({ skipped, result });
      if (riders) await fireDamageDealt(state, result);
      // ...and the mirror, on the Unit that took it.
      if (riders) await fireDamageTaken(state, result);
```

export function forcedModes(unit, items) {
  const compelled = new Set(
    (unit?.compulsions ?? [])
      .filter((c) => c.forcesSkill && (c.targetIds ?? []).length > 0)
      .map((c) => c.forcesSkill),
  );

/**
 * @param {object} unit
 * @param {object[]} items
 * @param {object} [ctx]
 * @param {number} [ctx.tick] the current global turn, for a live suspension
 * @returns {object[]}
 */
export function forcedModes(unit, items, { tick = 0 } = {}) {
  const compelled = new Set(
    (unit?.compulsions ?? [])
      .filter((c) => c.forcesSkill && (c.targetIds ?? []).length > 0)
      .map((c) => c.forcesSkill),
  );

  return [...(items ?? [])].filter((i) => {
    const sys = i.system ?? {};
    if (!sys.isMode || sys.active) return false;
    // Bought off for a span. Switching it back on here is exactly what the
    // Command Spell was spent to prevent.
    if (typeof sys.suspendedUntil === "number" && tick < sys.suspendedUntil) return false;
    return compelled.has(sys.slug ?? i.id) || forcedOn(i, unit);
  });

function stage7FlatAttackBonuses(s) {
  s.begin(7);
  let flat = 0;
  /** Flat bonuses that carry their OWN element, keyed by it. */
  const elemental = new Map();
  for (const m of activeMods(s, s.ctx.attacker, FLAT_ATTACK_KEYS)) {
    if (s.ctx.attack?.ignoresAttackerIncreases || s.bypass?.attacker) {
      const why = s.bypass?.attacker ? "bypassed by" : "ignored by";
      s.contribute(m.key, 0, `${m.source} (${why} this attack)`, "attacker");
      continue;
    }
    const value = magnitudeOf(m, s.isNP, s.ctx);
    // An elemental flat bonus is NOT part of the attack's own total: it is a
    // rider made of a different damage type. Added to the element's share so
    // the defender's resistance to THAT element meets it, and so it does not
    // drag the rest of the attack into a resistance it never had.
    if (m.element) {
      elemental.set(m.element, (elemental.get(m.element) ?? 0) + value);
      s.contribute(m.key, value, `${m.source} (${m.element})`, "attacker");
      continue;
    }
    flat += value;
    s.contribute(m.key, value, m.source, "attacker");
  }
  if (flat !== 0) s.addProportional(flat);
  for (const [element, value] of elemental) s.addElemental(element, value);
  s.end(7);
}
```

**Interfaces:**
- Consumes: `domain/enums.mjs#FACINGS` (`n, ne, e, se, s, sw, w, nw`) and `domain/geometry.mjs`'s screen convention (`+i` is south, `+j` is east).
- Produces: `orthogonalPanels(origin, facing, order, {bounds, occupied})` → `Array<{i, j}|null>`, one entry per name in `order`, `null` where no panel on that axis is free. Task 13's summon phase consumes it.

**The ruling (R4):**
> *"…which appear on the panels in front of her, behind her, and her left and right."*

Facing-relative. A panel that is off-board, occupied, or on another Scene Level pushes that clone **outward along the same axis** to the nearest free panel; if the axis offers none, that clone does not appear and the chat card says which and why.

**A diagonal facing is the case to get right.** `FACINGS` has eight members and four of them are diagonals. *"In front of"* a Servant facing `ne` is the panel at `(i−1, j+1)`; her "right" is `se`. The four directions are the facing rotated by 0°, 90°, 180° and 270°, which is the same rotation `coneOf` performs — so the arithmetic is derived from `FACING_DEGREES`, not tabulated.

/**
 * @file The four panels around a Unit, read off its facing.
 * @see docs/08-board-and-geometry.md §8.8, docs/superpowers/specs/2026-09-12-raikou-design.md R4
 *
 * Layer 2 (rules). Pure.
 *
 * Raikou's Goō Shōrai・Tenmōkaikai: *"four extra clones of herself, which
 * appear on the panels in front of her, behind her, and her left and right."*
 *
 * **Derived from `FACING_DEGREES`, not tabulated.** Four of the eight facings
 * are diagonals, and *"in front of"* a Servant facing `ne` is `(i−1, j+1)` --
 * so the four directions are the facing rotated by 0°, 90°, 180° and 270°,
 * which is the rotation `geometry.mjs#coneOf` already performs from the other
 * end. A hand-written 8×4 table would be 32 entries that have to agree with
 * that function for ever.
 *
 * **Displacement is OUTWARD along the same axis.** *"In front of her"* stays
 * in front of her: sliding a blocked clone onto a neighbouring axis would put
 * two copies on one side and none on another, which is a different formation
 * from the one the sheet draws.
 */

import { FACING_OFFSETS } from "../../domain/geometry.mjs";

/** The rotation each name applies to the facing, in degrees clockwise. */
const ROTATION = Object.freeze({ front: 0, right: 90, back: 180, left: 270 });

/**
 * One panel per name, in order, displaced outward where blocked.
 *
 * @param {{i: number, j: number}} origin the Unit's own panel
 * @param {string} facing one of `domain/enums.mjs#FACINGS`
 * @param {string[]} order which of `front`/`back`/`left`/`right`, and in which order
 * @param {object} opts
 * @param {{width: number, height: number}|null} opts.bounds
 * @param {Set<string>} opts.occupied `"i,j"` keys that are already taken
 * @param {number} [opts.maxDistance] how far outward to search before giving up
 * @returns {Array<{i: number, j: number}|null>} one entry per `order` entry
 */
export function orthogonalPanels(origin, facing, order, { bounds, occupied, maxDistance = 6 }) {
  // A live copy: each placement blocks the next, so a displaced clone cannot
  // land on a sibling that has not been placed yet.
  const taken = new Set(occupied);
  const out = [];

  for (const name of order) {
    const step = offsetFor(facing, ROTATION[name]);
    let found = null;
    for (let d = 1; d <= maxDistance; d++) {
      const panel = { i: origin.i + step.i * d, j: origin.j + step.j * d };
      if (bounds && (panel.i < 0 || panel.j < 0 || panel.i >= bounds.height || panel.j >= bounds.width)) break;
      const key = `${panel.i},${panel.j}`;
      if (taken.has(key)) continue;
      taken.add(key);
      found = panel;
      break;
    }
    out.push(found);
  }
  return out;
}
```

Export `FACING_OFFSETS` from `domain/geometry.mjs` (the eight `{i, j}` unit steps keyed by facing) if it does not already exist, and derive `offsetFor` from it — geometry is layer 1 and owns the convention.

 * one path. The golden tests hold Overedge and Tóole Fragarach byte-identical.

 * @param {object|null} damage the resolved `damage` block
 * @returns {object[]} one spec per instance, in declared order
 */
export function expandInstances(damage) {
  const d = damage ?? {};
  if (d.repeat !== undefined && d.instances !== undefined) {
    throw new Error("FGT | A damage block may declare `repeat` or `instances`, not both.");
  }
  const { repeat, instances, ...shared } = d;
  if (Array.isArray(instances)) {
    // The block's own fields are the default; an instance overrides them.
    return instances.map((i) => ({ ...shared, ...i }));
  }
  const n = Math.max(1, typeof repeat === "object" && repeat?.roll ? repeat.rolled ?? 1 : (repeat ?? 1));
  return Array.from({ length: n }, () => ({ ...shared }));
}

> *"Can only be used when Mad Enhancement is Active. Range=3. Hits a 3x3 panel area within Range. First, deal 0.5x damage four times using Base Attack (STR), each instance of damage respectively being Lightning damage (half), Fire damage (half), Ice damage (half) and Wind damage (half). **Two readings that are easy to get backwards.**
1. *"It is immediately ended"* — **it** is Tenmōkaikai. *"Its Cooldown"* — **Dohatsu Tenshou's own**, 6◈+⅔◈ becoming 8◈+⅔◈. Read the other way the clause would extend the cooldown of an ability that has already ended, which is a penalty on nothing.
2. **The Lightning asymmetry.** The four are each *"(half)"*; the fifth is *"Lightning damage"* with no parenthesis — full element share. A defender's Lightning ward bites the whole Noble Phantasm portion and half of the first instance.
