# Achilles — Implementation Plan

> **For agentic workers:** use `superpowers:executing-plans` to work through this task by task.
> Steps are checkboxes.

**Goal:** Build Achilles from `char_orig_sheets/Copia de Achilles.md` completely — thirteen
entries and five Noble Phantasms, with the twelve engine features they need built rather than
deferred.

**Architecture:** A new `stance` construct is the spine; every "while Mounted" clause becomes one
predicate against a roll option it emits. Four further mechanisms are new — a weak-point rung on
the reaction ladder, a defensive tier keyed on the *attacker's* Divinity, a directional knockback
with a damaging sidestep, and a duel field. Everything else is content against machinery that
already exists.

**Spec:** [`docs/superpowers/specs/2026-09-07-achilles-design.md`](../specs/2026-09-07-achilles-design.md)

## Global Constraints

- Layer discipline (`tools/check-layers.mjs`): `domain/` → `rules/` → `engine/` → `apps/`.
  Pure rules never touch a Foundry global.
- A new rule-element key goes in **both** `EXECUTORS` (`module/rules/elements.mjs`) and
  `RULE_ELEMENT_KEYS` (`tools/lib/content.mjs`); `test/unit/elements.test.mjs` holds them together.
- Read the **projection** (`unitFrom(boardSnapshot(), actor)` / `snapshotUnit`), never the
  document, for anything a rule element can move.
- Content changes need a pack rebuild, and that needs the **Foundry app closed**, not just the
  world shut down: stop every `Foundry Virtual Tabletop` process, `node tools/build-packs.mjs`,
  relaunch, POST `launchWorld` then `join`, navigate to `/game`. A `module/**` change needs only
  `node tools/fgt-reload.mjs`.
- Checks before the commit: `npm run lint`, `npx vitest run`, `npm run validate:content`,
  `npm run check:templates`, `npm run check:manifest`.
- Docs are part of the commit: the affected chapter in `00`–`44` **and** Ch. 45.
- Live-test in `fgt2026` as the GM, visually via claude-in-chrome. Report measurements.
