# Nemo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Captain Nemo plays exactly as `char_orig_sheets/Copia de Nemo.md` reads — thirteen clauses, including a dice-counting Attack Skill, a banded area attack, and a pocket dimension with an entry roll, a clock, a relocation and a Luck Check on his death.

**Architecture:** Every task pairs an engine addition with the clause that consumes it. Nothing lands inert — this project names "a rule that is right and inert" as its dominant defect, and Nemo arrives with one already waiting: stage 6 of the damage pipeline is *named after* Triton's Conch, reads `ctx.bandMultiplier`, and nothing writes that field.

**Tech Stack:** Foundry VTT v14, vanilla ESM, vitest, YAML content compiled by `tools/build-packs.mjs`.

**Spec:** [`docs/superpowers/specs/2026-09-11-nemo-design.md`](../specs/2026-09-11-nemo-design.md)

## Global Constraints

- **Layer rule.** `domain` (1) ← `rules` (2) ← `engine` (3) ← `apps`/`documents` (4). `rules/` and `domain/` never touch `game`, `canvas`, `ui`, `Hooks`. `npm run lint` runs `tools/check-layers.mjs`.
- **Closed vocabularies, enforced at build time.** Check the value exists before authoring:
  - anchors — `self`, `targetUnit`, `withinRange`, `selfEdgeAdjacent`, `fieldEdge`, `zone`, `movementPath`, `platform`, `global`, `sourceOfAttack`
  - shapes — `point`, `unit`, `square{size}`, `rect{w,h}`, `chebyshevRadius{r}`, `attackRange{r}`, `ring{r}`, `line{…}`, `orientedRect{short,long}`, `path`, `zone{zoneId}`, `banded{bands}`
  - `selection.chooser` — `all`, `nearest`, `random`, `chosen`
  - `modifierKey` — the closed set at `rules/damage/pipeline.mjs` `MODIFIER_KEYS`
  - roll options — every option a predicate names must match a pattern in `EMITTABLE` (`rules/options.mjs`), held by `test/unit/options.test.mjs`
  - rule element keys — one entry per key in `rules/elements.mjs#EXECUTORS`, mirrored in `rules/authoring/elements.mjs`, held in **both** directions by `test/unit/authoring-elements.test.mjs`
  - phase kinds — `PHASE_IDS` (`rules/authoring/phases.mjs`)
- **`actorSystem()` / `itemSystem()` in `tools/lib/content.mjs` are allowlists.** An authored field absent from them compiles to its schema default and the clause silently does nothing. `npm run validate:content` refuses unknown fields; it has caught six to date.
- **Every new localization key must resolve in `lang/en.json`** to exactly the English in the descriptor — `test/unit/authoring-i18n.test.mjs` holds both together.
- **Rebuilding packs needs the world down**: `node tools/fgt-rebuild.mjs`, never a bare `npm run build:packs`. The application holds the LevelDB open even with the browser tab closed.
- **Bringing the world up**: open a Foundry tab over CDP **first**, then `node tools/fgt-world.mjs launch`, then join. With no page, `launch` reports `pages: []` and fails silently.
- **Every commit updates the affected `docs/00-44` chapter AND `docs/45-implementation-status.md`.** Chapter 45 alone is not enough.

    // The sheet states no Class. Riding is Rider's class skill and is the only
    // class skill he carries, which is the whole of the derivation.

/**

function normalizeBypass(raw) {
  if (raw === true) return { attacker: true, defender: true };

```js
/**
 * @file The `diceCount` damage formula — damage as a count of dice over a threshold.
 * @see docs/36-case-remaining.md §36.6, docs/13-damage-pipeline.md
 *
 * Layer 2 (rules). Pure — no `Roll`, no documents. The caller evaluates the
 * dice and hands the faces in, which is what lets the whole shape be tested
 * without a world and what keeps the roll reproducible from the log.
 *
 * One ability in the corpus: Nemo's *Quickfire*. Its interest is not the
 * counting, which is trivial, but the THRESHOLD — four conditional modifiers,
 * one of which fires on a choice the defender makes during the Combat Process.
 * A player handed "you dealt 75" cannot check that number, so
 * {@link thresholdFor} returns every modifier it considered and whether it was
 * met, and the caller writes all of it to the roll log.
 */

import { test as testPredicate } from "../predicate.mjs";

/**
 * @typedef {object} ThresholdResult
 * @property {number} threshold the value a die must meet or beat
 * @property {Array<{delta: number, predicate: object[], met: boolean}>} applied
 */

/**
 * The threshold this use of the ability rolls against.
 *
 * Every modifier is evaluated and REPORTED, not merely the ones that fired: a
 * modifier that vanishes from the breakdown is indistinguishable from one that
 * was never collected, which is the rule the damage pipeline's own stages
 * follow for the same reason.
 *
 * @param {object} spec the ability's `damage.formula`
 * @param {{options: ReadonlySet<string>, refs: Record<string, unknown>}} ctx
 * @returns {ThresholdResult}
 */
export function thresholdFor(spec, ctx) {
  const t = spec?.threshold ?? {};
  const applied = (t.modifiers ?? []).map((m) => ({
    delta: m.delta ?? 0,
    predicate: m.predicate ?? [],
    met: testPredicate(m.predicate, ctx),
  }));

  // No clamp. The sheet states none, and four modifiers at -1 against a base
  // of 5 bottoms out at 1, which a d6 always meets -- a full 150 for pinning a
  // slower, stunned target at point-blank range and giving it no evade. That
  // is the ability working, not an overflow, so nothing here pretends
  // otherwise.
  const threshold = applied.reduce((n, m) => n + (m.met ? m.delta : 0), t.base ?? 0);
  return { threshold, applied };
}

/**
 * Damage from a set of rolled faces.
 *
 * @param {object} spec the ability's `damage.formula`
 * @param {number[]} rolls the evaluated faces, one per die
 * @param {number} threshold from {@link thresholdFor}
 * @returns {{successes: number, total: number}}
 */
export function damageFromDice(spec, rolls, threshold) {
  // "for each die that rolls X or HIGHER" -- the threshold itself succeeds.
  const successes = (rolls ?? []).filter((r) => r >= threshold).length;
  return { successes, total: successes * (spec?.perSuccess?.amount ?? 0) };
}
```

In `module/engine/attack.mjs`, where the damage context is built, before `computeDamage`:

```js
  // The `diceCount` formula (Nemo's Quickfire). The pipeline is pure and the
  // dice are not, so they are rolled here and the counted figure is handed in.
  // The threshold's four modifiers and each one's verdict go to the roll log
  // BEFORE the total: a player handed "you dealt 75" with no threshold cannot
  // check it, and this ability's threshold moves by up to four points.
  if (formula?.kind === "diceCount") {
    const { threshold, applied } = thresholdFor(formula, { options, refs });
    const roll = await new Roll(formula.dice).evaluate();
    const faces = roll.dice.flatMap((d) => d.results.map((r) => r.result));
    const { successes, total } = damageFromDice(formula, faces, threshold);
    log.record({ kind: "diceCount", ability: ability.id, threshold, applied, faces, successes, total });
    base = { diceTotal: total, successes, diceRolled: faces.length, threshold };
  }
```

```js
import { resolveTicks } from "../domain/tick.mjs";
import { chebyshev } from "../domain/geometry.mjs";

/**
 * How far the Storm Border may travel before it surfaces.
 *
 * > *"This distance is 2+X panels, where X=1 for every ⅓◈ Turns spent within
 * > Imaginary Numbers Space (e.g. 1◈ Turns spent, Nemo can travel 2+3=5)."*
 *
 * The worked example is a THREE-TURNS-PER-ROUND example and nothing else. ◈ is
 * turns-per-Round and varies by war variant — 3, 8 or 15 — so ⅓◈ is 1, 2 or 5
 * turns respectively (`TICK_OVERRIDES`, not `floor(turns/3)`, which disagrees
 * at every one of them). Hard-coding the 5 would silently shorten every war
 * that is not the Great Holy Grail War.
 *
 * @param {object} spec the platform's `dimension`
 * @param {{turnsInside: number, turnsPerRound: number}} ctx
 * @returns {number}
 */
export function travelDistance(spec, { turnsInside, turnsPerRound }) {
  const perStep = resolveTicks("⅓◈", { turnsPerRound });
  // `perStep` is never 0 for any supported variant, but a guard here is
  // cheaper than an Infinity reaching the placement validator.
  const steps = perStep > 0 ? Math.floor(turnsInside / perStep) : 0;
  return 2 + steps;
}

/**
 * Whether a chosen resurface destination is legal.
 *
 * Two clauses, and the second is ruling R3: *"excluding enemy Home Bases"*
 * bars the 5×5 from OVERLAPPING one, not merely from being centred on one. A
 * centre-only test would let a five-panel square land four-fifths inside an
 * enemy base.
 *
 * @param {object} spec the platform's `dimension`
 * @param {{at: {i: number, j: number}, from: {i: number, j: number},
 *          distance: number, board: object, factionId: string}} ctx
 * @returns {boolean}
 */
export function placementIsLegal(spec, { at, from, distance, board, factionId }) {
  if (chebyshev(at, from) > distance) return false;

  const { w, h } = spec.relocateOnExit.shape;
  const halfW = Math.floor(w / 2);
  const halfH = Math.floor(h / 2);
  const forbidden = new Set(
    (board.homeBases ?? [])
      .filter((b) => b.factionId !== factionId)
      .flatMap((b) => b.panels.map((p) => `${p.i},${p.j}`)),
  );

  for (let i = at.i - halfH; i <= at.i + halfH; i++) {
    for (let j = at.j - halfW; j <= at.j + halfW; j++) {
      if (forbidden.has(`${i},${j}`)) return false;
    }
  }
  return true;
}
```

/**
 * What happens to the Storm Border when Nemo dies inside it.
 *
 * > *"If Nemo is defeated while Zero Sail is Active, he performs a Luck Check
 * > **before dying**. If successful, the Storm Border immediately resurfaces
 * > (**but he is still defeated**); if failed, all Units within the Storm
 * > Border are inflicted with Erase."*

 * parenthesis is the whole point: the check saves the passengers and never
 * him. Offered as a `RevivalSource` it would compete with his own Guts in the
 * revival chain and, on a success, leave him alive — which the sheet denies in
 * the same sentence that grants the check.
 *
 * Pure, and called by the defeat resolution before the revival chain runs.
 *
 * @param {object|null} spec the platform's `dimension`, or null if not submerged
 * @param {{owner: object, succeeded: boolean, occupants: string[]}} ctx
 * @returns {{resurfaces: boolean, ownerStillDefeated: boolean, erased: string[]}|null}
 */
export function onOwnerDefeat(spec, { owner, succeeded, occupants }) {
  if (!spec?.onOwnerDefeat) return null;
  if (succeeded) {
    return { resurfaces: true, ownerStillDefeated: true, erased: [] };
  }
  // "ALL Units within the Storm Border" -- Nemo included. He is inside it.
  return { resurfaces: false, ownerStillDefeated: true, erased: [...occupants] };
}
