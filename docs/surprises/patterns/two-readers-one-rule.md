**Lesson:** Before adding or fixing a rule, grep for every other site that answers the same question. The preview, the bar and the card are readers too. Make them all call one reader, and fix the reader, not one site. An option set built away from the Attack Description is a second reader of the attack: the Miss check and the Damage Step's end each built their own and lost the range and the crit (Wave B). Effect entries now land through one door, `engine/landing.mjs`. Every option set a predicate is tested against is a reader too, wherever it is built (the selection filter, a bearer's own collection). A Unit named on a line or a prompt is `publicIdentityOf`'s, spoken through `publicSpeakerFor`: a new line that reads `actor.name` is a second reader. When a lesson lands, sweep the old sites it names too, not only the new ones; a rule that has slipped three times gets a guard, not another line. A derived state is a reader too: Unbound is derived from the pools and the Contract rule read the stored word; the tax read Grand Order from a context the Turn's end never filled, while the ban read the board's (#241). An offer is a reader of the use gate: a window, a rung or a prompt offers only what its press would pass (#243). The guard is #244. A Unit's document has one reader too, `engine/board.mjs#unitActor`: a summon's unlinked token shares its statblock's id, and 258 engine reads asked `game.actors.get` and got the statblock (#247). Foundry's own guess is a reader too: "which War" is `currentWar()`'s, never `game.combat`'s (whatever the tracker shows), `game.combats.active`'s (the activated scene's) or the tracker's own inference, which showed a stray global combat above another War's board (2026-10-18). A shared label function answers one question: the order strip's slots were all named after the acting combatant because the header's reader was reused. Put a new rule in the step every reader passes through (the spec the resolver reads), not after it in one caller; and format a prompt and its card through one function. A boundary handed a War reads that War's things only, on that War's rules: with several Wars running, a reader of 'every open dimension' is a reader of other Wars. A War Rule is read with `warRule(key, war)`, never `game.settings`; a list of Units is the War's board, never the canvas the viewer happens to show; a floor or cap on Health holds on every path that brings a Unit to 0, a terminal effect's included. A fact one stage derives reaches every reader before it too; a mirror event rolls its twin's dice; a card's verdict is the landing's own; a rule an effect authors is never hand-written again in the engine. Two writers of one state write one patch. A rule about a kind of effect asks its family, never one id; a seat is not a Class. Who a compulsion names is who its Attack may target.
