**Mechanism:** One question is answered in two places, and the answers drift. The bar's gate and the declaration's gate, two effect paths each reading a chance, a die rolled at dispatch and again at application, an entry gate reading a bare snapshot while its neighbours read the board, a click handler that never asks whether its slot is greyed, `isSpell` and `category: spell` disagreeing about what a Spell is, and a regen counter and `tickPeriodics` disagreeing about the Turn an effect stops. Raikou added the preview missing an element the resolution granted, an active mode's slot asking the activation gate, an instance's block read from the ability, and a damage-type resistance read at the stage for all damage. Mannanán and Kingprotea added the doors the engine opens on a Unit's behalf: an automatic counter and a cancellation stamping no Act where the ordinary counter did, a window use raising no `abilityUsed` where a cast and an attack did, two removal paths each reading `def.unremovable ?? instance`, and a timeout table naming `none` where the ladder says `nothing`. Serenity added a fix that landed in one reader while its sibling kept the slip: the check path read `ignoresResistanceFrom` and the rider loop did not, #190 dropped the invented `attack:kind:normal` on the roll path and `fireEvent` kept it, and `askOwner` routed every attacker question but the weak-point offer. EMIYA and the Dioscuri added more: the ally reaction path asked no requirement the own path asked, two movement refusals (leash, guarded panel) each printed as "occupied", the bar asking the budget only for attack abilities while `skill-use` billed a non-damaging NP, a restore line printing the authored delta beside a neighbour printing real numbers, an extension stamped right and restamped by the applier, the joint NP's Range and Crit read from the declarer while damage read both twins, and a second copy of the NP-category stamp. Proto Gil added the use gate weighing the NP table's cost while the payment charged the ability's own superseding cost, and a new engine line reading `actor.name` beside `publicIdentityOf`, the second True Name leak in two audits (Arturia's roll lines). Arjuna found the True Name leak a third time (#230 NV, #232 OJ, #234 OO): the lesson line covered the lines a feature wrote, and the old cards (Command Spell, boundary, periodic, revival) still read `actor.name`. Van Gogh (#239) added a periodic tick as a door: Sunflower's Curse's floor sat in the attack pipeline, which a Curse tick never enters; and the plain Evade rung spending no use of an automatic evasion the reaction path spent.
**Lesson:** Before adding or fixing a rule, grep for every other site that answers the same question. The preview, the bar and the card are readers too. Make them all call one reader, and fix the reader, not one site. An option set built away from the Attack Description is a second reader of the attack: the Miss check and the Damage Step's end each built their own and lost the range and the crit (Wave B). Effect entries now land through one door, `engine/landing.mjs`. Every option set a predicate is tested against is a reader too, wherever it is built (the selection filter, a bearer's own collection). A Unit named on a line or a prompt is `publicIdentityOf`'s, spoken through `publicSpeakerFor`: a new line that reads `actor.name` is a second reader. When a lesson lands, sweep the old sites it names too, not only the new ones; a rule that has slipped three times gets a guard, not another line. A derived state is a reader too: Unbound is derived from the pools and the Contract rule read the stored word; the tax read Grand Order from a context the Turn's end never filled, while the ban read the board's (#241).
