**Mechanism:** A special rule rides a generic mechanism, and the generic one offers exits the sheet forbids. Quickfire's no-roll Evade advanced as a failed Evade, which leads to Lucky Evasion. Zero Sail is a mode, and any mode's owner may toggle it off. An engine-only counter became a bar button through the generic `classifyUse`, and Possession's `maxUses: 1` bounded the button while its generic revival fired again.
**Lesson:** When a sheet bends a generic mechanic, list every exit the generic path offers (edges, toggles, prompts, buttons, revivals) and close each one the sheet rules out.
