**Mechanism:** A claim about when a phase runs was made from a name (`CASTER_PHASES`, "caster") without reading the set, and was retracted once the code was read.
**Lesson:** Before stating when or where something runs, open the set, the loop or the handler that runs it and quote it. A name is not evidence.
