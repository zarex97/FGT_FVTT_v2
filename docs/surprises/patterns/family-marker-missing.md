lesson: When a family of content files shares a marker, a new or older member that lacks it is a defect; scan the family, not the one file.
landed: none
---
**Mechanism:** Every Class Skill file says it is one (`kind: classSkill` or a `copyable` refusal), and five Riding files said neither, so Wisdom of Dún Scáith offered Medusa's Riding. Nothing reads "is this a Class Skill" from anything but the marker, so a file without it is silently the other thing.
**Lesson:** When a rule keys on a marker a family carries, grep the family for members without it before trusting the rule. One-off so far.
