lesson: A sheet governs its bearer: another Unit's side is its own sheet, and a condition one sheet states lives on that sheet's element, never in the reader others share. A phrase on one bearer's copy of a shared Skill is that bearer's own: read the shared text from a sheet that prints it plainly.

**Mechanism:** A clause about two Units (*"they will only Attack each other"*) was read as authority over the other Unit's behaviour. The user ruled that Arjuna's side is whatever Arjuna's sheet says. Van Gogh (#239) found its mirror: Sikera Ušum's "Units ... who are weak to Poison" was written into the one reader every `VulnerabilityAmplifier` shares, so Channel Marker Soul's halving of Curse never applied. Gilles de Rais (Saber) (#260) found it in a shared Skill's text: *"cannot be negated once Activated"*, printed on his copy of Mad Enhancement, was read as the Revised wording every bearer shares, while Darius III prints the plain clause and the phrase is Gilles's own exemption from Skill Seal.
**Lesson:** Build a sheet's clause for its bearer only. When a clause names another Unit's behaviour, note it as that Unit's to rule and leave it for that audit. When a clause carries a condition ("weak to", "while inside"), put it on the element that clause authors (`ifWeak`), and leave the shared reader unconditional. A phrase on one bearer's copy of a shared Skill is that bearer's own: read the shared text from a sheet that prints it plainly.
