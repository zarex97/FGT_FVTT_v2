**Mechanism:** A clause about two Units (*"they will only Attack each other"*) was read as authority over the other Unit's behaviour. The user ruled that Arjuna's side is whatever Arjuna's sheet says.
**Lesson:** Build a sheet's clause for its bearer only. When a clause names another Unit's behaviour, note it as that Unit's to rule and leave it for that audit.
