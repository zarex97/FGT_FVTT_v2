kind: producer-without-consumer
lesson: "Built" means everything a feature emits has a consumer, and every outcome has a line a player sees; grep for the reader before calling it done. A log entry is not a line: an outcome a player must know needs a card, not only io.log. A form field is built only once a test reads it back off the document it saved. A reader whose answer is never applied is no reader. A die that decides an outcome is on the card, and so is an attempt that fails. A flag a stage raises has a writer that acts on it, and every removal, done or held, is a line. A refusal names what it waits on. A field that is read has a writer. A record a run writes is read before it writes again, and a pool that is spent is refilled at every boundary that opens it. A batch goes through the door that puts its lines on the card (`applyWithLines`, `attack.mjs#applyOnCard`), and a key built from a value has a guard over every value. A clause its gate holds back is a line, and a card prints the reason a Process holds, never a generic label. A press reads each outcome off the card, never the sheet. A figure a sheet shows has a reader in the action it governs. An area a player must see is drawn for players.

**Mechanism:** Something is produced and nothing takes it: a hook nobody hears, an authored key nobody reads, a roll option nobody emits, a record nobody renders. The tests assert the YAML or the pure half, so they pass while the chain ends in mid-air. EMIYA and the Dioscuri added rolls and cuts with no line: Clairvoyance's die consumed and never shown, a handler's Cooldown cut and its die unreported, an Instakill that skipped damage and hid its effects, turn-start field events run and never reported, a wall refusal printing a field id. And events heard by nobody they named: a barrier's recipients never hearing the Combat Phase end, a Process end carrying no attack, `onRemove` heard only when a clock ran out, an NP's degeneration rate of -1 discarded. Proto Gil added a scheduled strike's clock moved by Golden Rule with no line: the count lives on the Combat flag, which no player opens. Arjuna added three: an `AttackProperty`'s predicate stored deferred and answered by nobody (Watermelon's Pierce on every Attack), Van Gogh's Regen `magnitude: 5` stored on an instance whose definition healed a literal 10, and Regen's heal at a Turn's end with no line on the card that names every loss. Van Gogh (#239) added a Turn's periodic damage, posted on a card at the Round's end only. The open-issues review (2026-10-19) added three outcomes said to nobody, a Conquest, a pre-emption and its Luck, and a declined Luck rung's reason, and a Delay that was stored, recomputed by `computeTurnOrder`, and never applied to the order played. Heracles added a revival card that hid the uses it spent and the dice that decided them, and a failed God Hand attempt that posted nothing at all. Anastasia (#258) added a pipeline flag, `removeFreeze`, that no engine file read, so a broken Freeze stayed on; a Noble Phantasm's removal whose held buffs reached no card; and an event rule's removal (Soaked dried, used up) said nowhere. Gilles de Rais (Saber) (#260) added three: summons that left the field with their summoner by a log entry only, a Master's death that freed his Servant by writes alone, Classic's −2◈ included, and a refusal that knew which ability it waited on and named none. The mirror: `MatchData.phase` had a reader and no writer, so every War opened on Day. Gilles (Caster) (#323) added four: a refusal string, `uncommandable`, that the Master's bar never read; the GM side's attack pool, spent by a GM-driven form and refilled by nothing; a Notebook page written and never read back, so a known NP rolled again and its miss denied it; and a transformation carded as a revival with a Health the form replaced. U-Olga Marie (#328) added three: a no-effect Attack printed "Missed", a revival's four Gyakkou effects were written and never said, and a phase its predicate held back was skipped in silence.
**Lesson:** For each thing a feature emits, find its consumer by grep before calling it built: `Hooks.on` for a hook, a reader for an authored key, the emitter for a predicate option, the renderer for a record. Then press the far end live. Every outcome a player must know about, resisted, ended or deferred, has a line on a card. Read each new line on screen as a player would: a raw key, a link code, or a reason that names the wrong Unit first is a line with no consumer (#206). A line prints what the write did, not what was asked, and names the Unit it landed on: a heal at full Health reads +0, and a buff shared to another body carries that body's name (#226). A `log` entry is not a line: the forest's escape and death die, a pickup and the Glass Game's rewind were each logged and read by nobody (#247). A form field is "built" only when a test reads it back off the document it saved: the wizard's Turns per Round was edited, shown on the Confirm tab and written nowhere, and its Confirm and Factions tabs printed keys and user ids no person can read (2026-10-18). A reader whose answer is never applied is no reader: follow the value to the place it changes play, not to the first function that reads it. A die that decides an outcome is printed on its card, and an attempt that fails gets a card of its own. A flag a stage raises has a writer that acts on it, and every removal, done or held, is a line. A refusal names what it waits on. A field that is read has a writer. A batch goes through the door that puts its lines on the card (`applyWithLines`, `attack.mjs#applyOnCard`), and a key built from a value has a guard over every value. A clause its gate holds back is a line, and a card prints the reason a Process holds, never a generic label. A press reads each outcome off the card, never the sheet. A figure a sheet shows has a reader in the action it governs. An area a player must see is drawn for players.
