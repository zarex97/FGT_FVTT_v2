**Mechanism:** Something is produced and nothing takes it: a hook nobody hears, an authored key nobody reads, a roll option nobody emits, a record nobody renders. The tests assert the YAML or the pure half, so they pass while the chain ends in mid-air. EMIYA and the Dioscuri added rolls and cuts with no line: Clairvoyance's die consumed and never shown, a handler's Cooldown cut and its die unreported, an Instakill that skipped damage and hid its effects, turn-start field events run and never reported, a wall refusal printing a field id. And events heard by nobody they named: a barrier's recipients never hearing the Combat Phase end, a Process end carrying no attack, `onRemove` heard only when a clock ran out, an NP's degeneration rate of -1 discarded. Proto Gil added a scheduled strike's clock moved by Golden Rule with no line: the count lives on the Combat flag, which no player opens. Arjuna added three: an `AttackProperty`'s predicate stored deferred and answered by nobody (Watermelon's Pierce on every Attack), Van Gogh's Regen `magnitude: 5` stored on an instance whose definition healed a literal 10, and Regen's heal at a Turn's end with no line on the card that names every loss. Van Gogh (#239) added a Turn's periodic damage, posted on a card at the Round's end only.
**Lesson:** For each thing a feature emits, find its consumer by grep before calling it built: `Hooks.on` for a hook, a reader for an authored key, the emitter for a predicate option, the renderer for a record. Then press the far end live. Every outcome a player must know about, resisted, ended or deferred, has a line on a card. Read each new line on screen as a player would: a raw key, a link code, or a reason that names the wrong Unit first is a line with no consumer (#206). A line prints what the write did, not what was asked, and names the Unit it landed on: a heal at full Health reads +0, and a buff shared to another body carries that body's name (#226).
