**Mechanism:** A rule source the work needs is missing from the repository, a connector (Google Drive, the web) is available, and its availability is read as permission. Clauses and readings then rest on text the user never chose to bring into the project.
**Lesson:** Rules come from the repository's docs, its source sheets and its issues. When one is missing, say which and ask the user for it; search a connector only when told to.
