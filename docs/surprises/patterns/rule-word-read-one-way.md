**Mechanism:** A rulebook phrase with two readings is built on one, without checking how the same document uses the words elsewhere. Aim *"ignores Dodge and the Evade action"* was built as the `Evade` buff, while the Dodge line beside it uses "the Evade action" for the rolled Evade.
**Lesson:** Before building a phrase that names a game term, grep the same document for that term's other uses. When two readings remain, put both to the user with their sources.
