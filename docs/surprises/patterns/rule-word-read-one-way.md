**Mechanism:** A rulebook phrase with two readings is built on one, without checking how the same document uses the words elsewhere. Aim *"ignores Dodge and the Evade action"* was built as the `Evade` buff, while the Dodge line beside it uses "the Evade action" for the rolled Evade. Mad Enhancement's "halved on an attack that uses BA(MAG)" was built as the MAG component, while Mana Burst declares `component: str` and uses MAG as its base. 'Acts' was built to exclude switching a mode on, though the ruling it came from said a Turn she used an ability (#194). The sheet survey (2026-10-21) added two: a Class filled in from Class Skills (Durga read Saber or Rider, and she is an Archer), and `{R}` `{M}` `{S}` read as decoration when they say Ranged, Melee or Special, a fact the engine had been guessing from distance. Anastasia (#258) added three: Soaked's *"additive"* read as its whole clause, a class her sheet never prints filled in as Caster and read as one by four readers, and Rule Breaker meeting Independent Action, never asked until a press made it happen. A reading ruled for one Servant and carried into another's grill is the same mistake: Penthesilea's "Acting" carried to Raikou, Ramesseum's narrow ZON clause carried to Wallachia (merged from `precedent-carried-without-asking`, 2026-10-24).
**Lesson:** Before building a phrase that names a game term, grep the same document for that term's other uses. When two readings remain, put both to the user with their sources. A list shared by two rules is a reading too: Presence Concealment sat beside Huge Scale in one list that both passing and stopping read, so *"Move to any panel"* became "stop on any Unit" (#226 reading 28). An event's name is a rule word too: read it against the clause that listens to it (`damageTaken` fires on a hit for 0, Avalon heals only after damage). A value the sheet leaves out is a reading too, never a guess; so is one sheet's clause meeting another's. A mark the sheet prints is a term too: ask what it means before reading it as layout. A reading carried from another audit goes to the user with its source and its scope.
