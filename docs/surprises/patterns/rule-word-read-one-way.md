**Mechanism:** A rulebook phrase with two readings is built on one, without checking how the same document uses the words elsewhere. Aim *"ignores Dodge and the Evade action"* was built as the `Evade` buff, while the Dodge line beside it uses "the Evade action" for the rolled Evade. Mad Enhancement's "halved on an attack that uses BA(MAG)" was built as the MAG component, while Mana Burst declares `component: str` and uses MAG as its base.
**Lesson:** Before building a phrase that names a game term, grep the same document for that term's other uses. When two readings remain, put both to the user with their sources.
