**Mechanism:** A ruling recommended against the system's default because the default was never written down anywhere. Quickfire's *"only performs an Injury Roll once, regardless of number of hits"* exists only because the default is one roll per hit, and Dohatsu Tenshou, which says nothing, was first recommended one roll.
**Lesson:** Before recommending a reading for a silent sheet, look for a sheet that opts out of the same thing; its opt-out names the default.
