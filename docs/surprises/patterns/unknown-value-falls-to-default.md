**Mechanism:** Content authors a value the executor reading it does not know, and the executor does its default thing instead of refusing. `target: linkedGroup` fell to the caster, so "both twins" restored one. A `CooldownDelta` written inside an `applyEffects` phase read as an entry with no effect id, and the cut landed nowhere. A rank table's `amount` was unread, so the clock was set to 0. A handler's `until <event>` duration was dropped, so the effect never ended. It is the Silent Drop seen from the executor: the key survives every Hop and dies at the switch that reads it. Proto Gil added a guard's catch-all: the answer for an unanswerable rung sent `nothing` to any Process with no prompt, and a `missed` Process, a state it was not written for, threw. Arjuna added a free-text `AttackProperty.property`: Watermelon granted `ignoreDef` beside every reader's `ignoresDefUp`, and nothing refused it. Kiritsugu (#243) added two writers: Magecraft named `DurationExtension`, a standing element, as a handler action, and `dispatch` only logged `unhandledAction`; a clamped restore keyed `luck`, the `{value, max}` pool, and `adjustStat` added 4 to an object and wrote nothing. Yan Qing (#253): `relations: [any]` passed validation, which checked `chooser` and not `relations`, and the resolver refused every Unit when the ability was used.
**Lesson:** When content gains a value (a target, a phase kind, a duration form, a table shape), find the switch that reads it and look at its default branch. An unknown value refuses out loud: it throws in tests and names itself in the validator. The guard that checks the vocabulary walks every nesting where the value can sit (a `choose` branch's phases, a handler's actions), not only the top level. A writer refuses a value it cannot write, as `io.mjs#adjustStat` now refuses a path that is not a number. A rolled maximum has a floor: a plan line's `min` (the Normal Lancer's Luck, ruled 2026-10-18). The content validator checks every closed vocabulary a resolver reads (anchors, shapes, choosers, relations), so an unknown word fails the build, not the use.
