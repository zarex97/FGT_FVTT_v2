**Mechanism:** Content authors a value the executor reading it does not know, and the executor does its default thing instead of refusing. `target: linkedGroup` fell to the caster, so "both twins" restored one. A `CooldownDelta` written inside an `applyEffects` phase read as an entry with no effect id, and the cut landed nowhere. A rank table's `amount` was unread, so the clock was set to 0. A handler's `until <event>` duration was dropped, so the effect never ended. It is the Silent Drop seen from the executor: the key survives every Hop and dies at the switch that reads it. Proto Gil added a guard's catch-all: the answer for an unanswerable rung sent `nothing` to any Process with no prompt, and a `missed` Process, a state it was not written for, threw. Arjuna added a free-text `AttackProperty.property`: Watermelon granted `ignoreDef` beside every reader's `ignoresDefUp`, and nothing refused it.
**Lesson:** When content gains a value (a target, a phase kind, a duration form, a table shape), find the switch that reads it and look at its default branch. An unknown value refuses out loud: it throws in tests and names itself in the validator. The guard that checks the vocabulary walks every nesting where the value can sit (a `choose` branch's phases, a handler's actions), not only the top level.
