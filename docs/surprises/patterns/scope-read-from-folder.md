---
kind: scope-read-from-folder
lesson: A guard's scope is a named list, never whatever a folder happens to hold.
landed: none
---
**Mechanism:** A test built "the audit programme's scope" from every Character Sheet in `char_orig_sheets/`, so fifteen sheets copied in for later Servants joined it the moment they landed and failed for Clauses nobody had named yet.
**Lesson:** A guard that covers "every X in scope" reads the scope from a list that changes only by decision (an issue, a named array), never from the contents of a folder something else writes to.
