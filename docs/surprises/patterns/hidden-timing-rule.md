**Mechanism:** When something runs is set by a rule written elsewhere, not by where it is written. A phase listed first runs after damage without `when: beforeDamage`. A death check ordered literally runs ahead of the revival chain. A `revival:` predicate is answered at collection unless `DEFERRED_PREFIXES` holds it. "If her Master has 25 or less and would lose it" is a moment, not a state; `turnEnd` is only her own side's Turn; a defeated body stays a Turn. An exception keyed to when charges were stamped rather than when the ability was used; a Range read after the ride had already moved her.
**Lesson:** For each ordering word in a clause, find the key that decides its timing (`when`, `DEFERRED_PREFIXES`, the revival chain, the ladder's `TRANSITIONS`) and press the order on a live board.
