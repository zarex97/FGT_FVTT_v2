(Xu Fu) Class Skill: Settlement Creation — Rank: EX  
(Passive 1\) When this Unit is in its Home Base, all damage dealt by it is increased by 6d20 after calculation including NP.  
(Passive 2\) While this Unit is on the field, all damage taken by allied Units who are in their Home Base is further reduced by (3d10+30) including NP.  
(Active) Used during your Turn. When this Skill is used, mark a 7x7 panel area around Xu Fu. This area will be termed as the ‘Settlement’ area, and cannot overlap any existing Home Bases. The Settlement area counts as a Home Base for Xu Fu and her allies. Only one Settlement area can exist at any time.  
Note: This Skill is categorized as ‘Territory Creation’. If there are multiple allied Units with this Skill, only the Territory Creation with the highest Rank takes effect (i.e. Territory Creation does not stack).  
Note on Settlement: If an AoE NP is used on a Unit(s) within a Settlement, the Settlement has a X% chance of being destroyed, where X=damage dealt by the NP divided by 10\. If the NP deals Fire damage, X is doubled.

(Xu Fu) Class Skill: Item Construction — Rank: B+  
This Skill affects all allied Units within a 2 panel area of this Unit.  
(Passive 1\) The chance of inflicting debuffs is increased by 45%; this effect is halved for Instakill (25%), and further halved for Death (15%).  
(Passive 2\) The chance of being inflicted by debuffs is reduced by 45%; this effect is halved for Instakill (35%), and further halved for Death (15%).  
Note: If a Unit is affected by multiple instances of this Skill, only the Item Construction with the highest Rank takes effect (i.e. Item Construction does not stack).  
(Active) Used during your Turn. Create 1d8 Talismans; if used while within her Home Base, increase the number created by 2\. Cooldown: 2◈ Turns.
