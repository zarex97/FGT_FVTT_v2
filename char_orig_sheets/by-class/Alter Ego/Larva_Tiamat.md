(Larva) Infantile Regression — Rank: A

(Active) Used during your Turn. Can only be used once per Round. If Tiamat is not in Mature Form, she transforms into Mature Form. Gains the following effects while in Mature Form-

(Larva) Sea of Azure Stars — Rank: A  
(Active) Used during your Turn. Can only be used once per Round. Affects all allied Units within a 3 panel area of herself. Has the following effects-  
1\. Restores their Health by 10% of their maximum value (plus 100\).  
2\. Reduce their NP Cooldown by ½◈ Turns (1◈ Turns).  
3\. Apply NP DmUp for ⅓◈ Turns, NP Damage dealt is increased by 10% (20%).  
Then, remove X number of Larva Counters from herself, where X=the number of allied Units affected by this Skill excluding herself. If she had less than X Larva Counters when this Skill was used, she gains an Azure Mark for every insufficient Larva Counter.  
Azure Marks are categorized as an Unremovable debuff and have the following effect- Base Attack (MAG) is reduced by 20 for every Azure Mark on this Unit. At the end of the Round and whenever this Unit’s Health is restored by a non-Passive effect, remove one Azure Mark from this Unit.  
Sea of Azure Stars cannot be used if Tiamat has any Azure Marks.
