(MedeaLily) Class Skill: Item Construction — Rank: B  
This Skill affects all allied Units within a 2 panel area of this Unit.  
(Passive 1\) The chance of inflicting debuffs is increased by 40%; this effect is halved for Instakill (20%), and further halved for Death (10%).  
(Passive 2\) The chance of being inflicted by debuffs is reduced by 40%; this effect is halved for Instakill (20%), and further halved for Death (10%).  
Note: If a Unit is affected by multiple instances of this Skill, only the Item Construction with the highest Rank takes effect (i.e. Item Construction does not stack).

(MedeaLily) Class Skill: Territory Creation — Rank: B  
(Passive 1\) When this Unit is in its Home Base, all damage dealt by it is increased by 5d10 including NP.  
(Passive 2\) While this Unit is on the field, all damage taken by allied Units who are in their Home Base is further reduced by (3d10+15) including NP.  
Note: If there are multiple allied Units with this Skill, only the Territory Creation with the highest Rank takes effect (i.e. Territory Creation does not stack).
